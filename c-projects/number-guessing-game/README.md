# Number Guessing Game

The program chooses a random number between 1 and 100. You keep guessing until you find it, and it tells you whether your guess should be higher or lower.

It also counts how many attempts you needed.

## Build and run

~~~bash
gcc -std=c11 -Wall -Wextra number_guessing_game.c -o guessing_game
./guessing_game
~~~

## What I practised

- Loops and conditional statements
- Generating random numbers
- Taking and checking user input
- Keeping track of attempts
