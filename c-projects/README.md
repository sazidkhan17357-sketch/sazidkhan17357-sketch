# C Programming Projects

Small, practical C programs built to strengthen programming fundamentals.

## Projects

| Project | Concepts |
|---|---|
| [Command-line Calculator](calculator/) | Functions, switch statements, input validation |
| [Number Guessing Game](number-guessing-game/) | Loops, conditionals, random numbers |
| [Student Grade Manager](student-grade-manager/) | Structures, arrays, functions |
| [Contact Management System](contact-management-system/) | Structures, strings, file handling, CRUD operations |

## Compile

Use GCC:

```bash
gcc filename.c -o program
./program
```

Each project folder contains its own source code and instructions.
